## ⚡ Local Development & Deployment
This project is configured for seamless deployment to the edge via Cloudflare.

1. Clone the repository:
   ```bash
   git clone [https://github.com/amineelmoufid/resume.git](https://github.com/amineelmoufid/resume.git)
   cd resume

2. Ensure you have the Wrangler CLI installed.

3. Install dependencies:

Bash
npm install
4. Start the local development environment:

Bash
wrangler pages dev
